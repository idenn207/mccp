## 저장소 맥락

mccp는 Claude Code 플러그인으로:
- 무인 자동화 파이프라인(PRD→plan→implement→PR) 목표
- receipt 봉인으로 의사결정 추적 및 감사 corpus 유지
- 다중 모델 dual-review 체계(Claude vs Codex)
- 운영자의 최우선 제약: deadline(하루~1주/마일스톤)

## 검증 요청

아래의 findings / recommendations를 **적대적으로** 검증하라.

1. 거짓이거나 과장된 주장을 찾아라
2. 이미 해결된 것을 미해결로 본 경우를 지적하라
3. 놓친 더 큰 결함을 발견하면 추가하라
4. 증거 인용이 부정확하면 정정하라
5. confidence 수치가 근거 대비 과하거나 부족하면 조정하라

## 최종 형식

마지막에 정확히 이 형식으로 요약하라:

```
VERDICT: converged|divergent
DISAGREEMENTS:
- <target>: <codex 위치> — <이유> (severity: high|medium|low)
ENDORSED: <찬성하는 항목 id 나열>
ADDITIONS:
- <새로 발견한 것>
```
