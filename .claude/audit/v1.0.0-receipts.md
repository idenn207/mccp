## v1.0.0 Ship Implication

- **STOP_RELEASE 트리거**: 4d self-trap (Type E + Next-step 5 단일 row 이중 충족). 단, Windows 사용자는 PowerShell tool 우회 가능 — Linux/macOS-only 사용자에게만 진짜 BLOCKING. **환경 분기 평가가 W-VERDICT의 결정 포인트**.
- **CONDITIONAL 트리거 (병행)**: 평균 decision-type 3.0 = HIGH UX defect threshold 정확 일치. STOP_RELEASE가 더 strong하므로 우선.
- **HIGH patch 후보 4건**: F-B (validate path derive-decision), 4a (write 자동 복구 + fallback 안내 부재), 4c (marker idempotency), 4d (guard hook `pid_alive` 검증 부재 + 안내 자기 모순).
- **자동 path 성공률**: 5건 중 2건 (4b, 4e). 3건은 자동 fail 후 수동 복구 필요 — receipt 손상은 mccp가 광고하는 "mechanical enforcement"의 약점 노출 영역. v1.0.0 정체성 ("multi-model dual reviewer" + 자동 게이트) 신뢰도에 영향.
- **권장 patch 우선순위**: 4d → F-B → 4a → 4c. 4d는 dogfood 자체가 자기 손에 잡힌 사례 — 자기 입증 BLOCKING.
