## Rubric (snapshot of plan v0.5 §UX Decision-Type Rubric)

**Decision Type** (사용자에게 요구된 결정 형식):
- A (1) = yes/no 단답 — 이상적, 최종 승인자 mode
- B (2) = ≤3 picker
- C (3) = 1-token 단답
- D (4) = 구조화된 multi-token 입력
- E (5) = free-form debug — **결함**

**Next-step 명료성** (다음 step이 어떻게 전달되는가):
- 1 = 1줄 stdout으로 명시
- 2 = stderr/메시지에서 추론 가능
- 3 = docs/CLAUDE.md 검색 필요
- 4 = memory에서 떠올림
- 5 = 불명확 — 사용자가 처음부터 재설계

**임계**:
- 평균 ≥ 3.0 (T 또는 NS) → CONDITIONAL ship
- 단일 row가 Type E (5) OR Next-step 5 → **STOP_RELEASE**
