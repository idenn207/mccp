## 5. Cross-cutting Observations

### O1 — receipt chain 자동 복구는 mccp 정체성의 약점

W4 (receipts) 5건 시나리오 중 자동 복구 성공률 = 2/5 (4b, 4e). 3건은 자동 fail 후 수동 복구 필요. mccp가 표방하는 "multi-model dual reviewer + 자동 게이트"의 자동성이 receipt 손상 시나리오에서 노출. 단 자동 진단 정확도는 5/5 — 사용자에게 "무엇이 깨졌는지"는 정확히 emit. 약점은 "복구 단계의 1줄 명령" 명료성이고, PR #20이 이를 W11 11j+11k 두 row 차원에서 해소.
